# Regla de Sincronización con GitHub Desktop

Cada vez que se complete una modificación o mejora en el código del proyecto, recuerda SIEMPRE al usuario los pasos en GitHub Desktop para desplegar los cambios en Vercel:
1. Abrir **GitHub Desktop**.
2. Hacer clic en **"Commit to main"** (abajo a la izquierda).
3. Hacer clic en **"Push origin"** (arriba a la derecha).
4. Esperar ~45 segundos para que Vercel actualice la web en vivo en https://opos-study-platform.vercel.app.
